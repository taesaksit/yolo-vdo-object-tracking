# Vehicle Line Crossing Project

บันทึกสรุปขั้นตอนการพัฒนาโปรเจกต์นับจำนวนรถข้ามเส้นด้วย YOLO และ OpenCV แบ่งเป็น 4 แนวทาง:

## 1. Concept Crossing Line (`concept-crossingline.py`)
* วาดเส้นและจำลองการเคลื่อนที่ของรถด้วย OpenCV แบบภาพนิ่ง
* **หลักการเบื้องต้น:** เช็คเงื่อนไข `prev_y < line_y` และ `curr_y >= line_y` เพื่อดูว่าวัตถุเคลื่อนที่จากเหนือเส้นข้ามลงมาใต้เส้นหรือไม่

## 2. Custom Solution (`custom-soltion.py`)
* เขียนฟังก์ชันคำนวณทางคณิตศาสตร์เอง (ใช้ Cross Product เช็คฝั่งเส้นตรง เพื่อรองรับเส้นเฉียง)
* **หลักการเพิ่มเติม:** 
  * เก็บประวัติพิกัดเทียบระหว่างเฟรมก่อนหน้ากับปัจจุบัน (`prev_point` และ `curr_point`)
  * เช็คการตัดผ่านเส้น และใช้ `Set` เก็บ `track_id` เพื่อป้องกันการนับซ้ำ

## 3. Solution from Ultralytics (`solution-from-ultralytics`)
* ใช้ฟังก์ชันสำเร็จรูป (`solutions.ObjectCounter`) จากไลบรารี Ultralytics
* **หลักการทำงาน:** ระบบจัดการการตรวจจับ ติดตามวัตถุ (Tracking) และคำนวณการตัดผ่านเส้นให้แบบเบ็ดเสร็จในตัว

## 4. Logic Rule (Line Crossing Condition)
* **หลักการนับผ่านเส้น:** หากกำหนดเส้นไว้ที่ตำแหน่ง $Y = 100$ แล้ววัตถุ (กล่องสี่เหลี่ยม) เคลื่อนที่จากเฟรมก่อนหน้าที่อยู่เหนือเส้น (เช่น $Y = 99$) แล้วข้ามลงมาอยู่ใต้เส้นหรือทับเส้นในเฟรมปัจจุบันที่ $Y \ge 100$ (เช่น $Y = 101$) ระบบจะถือว่าข้ามผ่านและนับคะแนนทันที (+1) พร้อมบันทึก ID ป้องกันการนับซ้ำ
